# kadr

Конвейер одного видео для канала с рисованными видео-эссе: от замысла до готового
mp4 со звуком и субтитрами. Работает на этой машине, без аккаунтов и без оплаты.

## Что он делает

Одно видео — один проект. Внутри девять стадий, каждая считается отдельно и
сохраняется на диск:

| № | Стадия | Что получается |
|---|--------|----------------|
| 1 | `transcript` | разбор референсного видео: ниша, тон, формула, темп + 6 идей |
| 2 | `niche` | замысел: спрятанный механизм, кто на нём зарабатывает, финальный поворот |
| 3 | `style` | паспорт стиля + дословный английский блок стиля + лист персонажей |
| 4 | `params` | длина, язык, цели по словам, кадрам и анимациям |
| 5 | `script` | раскадровка по кадрам: реплика, что на экране, флаг анимации |
| 6 | `image_prompts` | английский промт на каждый кадр, с блоком стиля дословно |
| 7 | `video_prompts` | промты оживления только на помеченные кадры |
| 8 | `voice` | озвучка + тайминги слов + субтитры |
| 9 | `assemble` | готовый mp4: панели с медленным движением, голос, субтитры |

## Чем это отличается от «промпта в чате»

Промпт задаёт правила словами. На видео в восемь минут это 120 с лишним кадров и
столько же промтов, и нейросеть нарушает правила тихо: пропустит блок стиля,
поставит анимацию на половину кадров, напишет на треть меньше текста. Здесь
каждое правило превращено в число и проверяется кодом (`src/validate.js`), а
сценарий прогоняется через петлю починки: замечания уходят обратно модели вместе
с её прежним ответом, пока проверка не станет чистой.

Что именно проверяется:

- слов в озвучке — под требуемую длительность (150–190 слов в минуту);
- кадров — 15–18 на минуту, номера идут подряд;
- анимаций — не больше четверти кадров (эталон ниши сдержанный);
- у каждого кадра есть реплика и описание того, что видно;
- блок стиля в каждом промте картинки совпадает **посимвольно**;
- промты анимации стоят только на помеченные кадры и содержат запреты (камера
  стоит, стиль не меняется, морфинга нет);
- описания персонажей не дублируются и встречаются дословно.

## Бесплатный стек

| Что | Чем | Нужен ключ |
|-----|-----|------------|
| Текст (сценарий, промты) | Gemini, при отказе — Groq | да, оба бесплатные |
| Озвучка | Microsoft Edge Neural через `edge-tts` | **нет** |
| Панели (рисунки) | собственный рисовальщик кодом, SVG → PNG | **нет** |
| Сборка видео | `ffmpeg` локально | **нет** |

Озвучка проверена вживую: 322 голоса, два русских (`ru-RU-DmitryNeural`,
`ru-RU-SvetlanaNeural`), пословные тайминги с точностью до миллисекунды. Важная
деталь: тайминги приходят только если явно попросить `boundary="WordBoundary"`,
иначе сервис отдаёт один звук.

Рисовальщик панелей (`src/providers/render.js`) рисует человечков и предметы
кодом, а линия при этом дрожит: каждая черта — кривая с детерминированным
смещением от номера кадра. Поэтому панели не тратят квоту, не зависят от чужих
серверов и повторяемы — один и тот же кадр всегда выглядит одинаково.

## Что не работает бесплатно (проверено)

- **NVIDIA** с текущим ключом даёт только текстовые модели: `/images/generations`
  и `genai/flux_1-dev` отвечают 404, среди 81 доступной модели нет ни одной
  диффузионной. Чтобы получить доступ к FLUX, нужно на странице модели на
  build.nvidia.com нажать «Get API Key» — ключ выдаётся на конкретную модель.
- **Gemini** перечисляет модели изображений (`gemini-2.5-flash-image`,
  `gemini-3-pro-image` и другие), но на бесплатном тарифе отвечает 429 с
  `limit: 0` — генерация картинок в бесплатный тариф не входит.

Поэтому генерация изображений подключена как сменный слой: есть российский путь
(свой рисовальщик), есть экспорт промтов для ручной генерации в любом сервисе, и
есть место, куда встанет NVIDIA или Gemini, когда появится доступ.

## Запуск

```bash
cd ~/kadr
cp .env.example .env      # вписать ключи
node src/server.js        # интерфейс на http://127.0.0.1:4173
node src/worker.js        # воркер очереди (отдельным окном)
node --test test/         # проверки
node scripts/demo.mjs     # полный прогон одной темы в projects/<id>/
```

Задания ставит интерфейс, выполняет воркер: сценарий на восемь минут — это
несколько обращений к модели подряд, и держать из-за них открытым браузер
незачем. Воркер переживает перезапуск — очередь лежит в SQLite
(`node:sqlite`, ничего ставить не надо).

Стадия считается готовой, если рядом лежит `<стадия>.json`. Повторный прогон
берёт готовое и не жжёт квоту; `KADR_FORCE=1` заставляет пересчитать заново.

## Проверки

```bash
node --test test/
```

Покрыты правила конвейера: длина сценария, частота кадров, метки анимации,
посимвольное совпадение блока стиля, запреты в промтах оживления, различимость
персонажей.
